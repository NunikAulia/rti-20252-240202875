# Tahap 3 - Pengumpulan Data Kuesioner

**Status:** Selesai  
**Bergantung pada:** Tahap 2 - Penyusunan Instrumen Penelitian

---

## Tujuan

Melaksanakan pengumpulan data primer melalui penyebaran kuesioner kepada pelaku UMKM bermitra Grab di Kabupaten Garut.

Pengumpulan data dilakukan untuk memperoleh informasi mengenai:

- Manfaat yang dirasakan dari penggunaan e-commerce.
- Kapabilitas teknologi pelaku UMKM.
- Tingkat adopsi e-commerce.
- Peningkatan omzet UMKM setelah menggunakan e-commerce.

---

## Deliverable

- Kuesioner penelitian final.
- Daftar target responden UMKM bermitra Grab di Kabupaten Garut.
- Data primer hasil pengisian kuesioner.
- Dataset awal dalam format Microsoft Excel (.xlsx).
- Pemeriksaan kelengkapan jawaban responden.
- Dataset siap digunakan untuk validasi dan analisis menggunakan SmartPLS.

---

## Desain Pengumpulan Data

| Komponen | Keterangan |
|----------|------------|
| Jenis Data | Data Primer |
| Metode Pengumpulan | Kuesioner |
| Skala Pengukuran | Skala Likert 1–5 |
| Responden | Pelaku UMKM Mitra Grab |
| Lokasi Penelitian | Kabupaten Garut |
| Jumlah Responden | 100 Responden |
| Format Data | Microsoft Excel (.xlsx) |
| Software Analisis | SmartPLS |

## Struktur Dataset

| Kolom | Keterangan |
|--------|------------|
| ID_Responden | Kode responden (R001–R100) |
| X1.1–X1.3 | Indikator Manfaat yang Dirasakan |
| X2.1–X2.3 | Indikator Kapabilitas Teknologi |
| X3.1–X3.3 | Indikator Tingkat Adopsi E-commerce |
| Y1–Y3 | Indikator Peningkatan Omzet UMKM |
| Lama_Usaha | Lama usaha responden |
| Pendidikan | Tingkat pendidikan responden |

---

## Hasil Pengumpulan Data

Pengumpulan data berhasil memperoleh **100 responden** pelaku UMKM mitra Grab di Kabupaten Garut. Seluruh responden mengisi kuesioner menggunakan skala Likert 1–5 dan memenuhi kriteria penelitian.

| Keterangan | Jumlah |
|------------|--------|
| Target Responden | 100 |
| Data Masuk | 100 |
| Data Tidak Lengkap | 0 |
| Data Valid | 100 |

---

## Pemeriksaan Awal Data

Sebelum dilakukan analisis menggunakan SmartPLS, dilakukan proses pemeriksaan awal terhadap dataset dengan hasil sebagai berikut:

- Seluruh responden memiliki kode identitas yang unik.
- Tidak terdapat data kosong (missing value).
- Seluruh jawaban berada pada rentang skala Likert 1–5.
- Format data telah sesuai dengan instrumen penelitian.
- Dataset siap digunakan untuk proses validitas, reliabilitas, dan analisis SEM-PLS.

---

## Catatan Pelaksanaan

Pengumpulan data dilakukan secara langsung kepada pelaku UMKM mitra Grab di Kabupaten Garut menggunakan instrumen kuesioner yang telah melalui tahap validasi isi. Seluruh jawaban dikumpulkan, diperiksa kelengkapannya, kemudian disusun ke dalam dataset Microsoft Excel sebagai dasar pengolahan data menggunakan SmartPLS.

---

## Keputusan Teknis

1. Jumlah responden yang digunakan sebanyak **100 responden**.
2. Instrumen menggunakan skala Likert 1–5.
3. Dataset disimpan dalam format **Microsoft Excel (.xlsx)**.
4. Setiap responden diberikan kode **R001 sampai R100**.
5. Data yang tidak lengkap tidak diikutsertakan dalam analisis.
6. Dataset final digunakan sebagai input analisis SEM-PLS pada SmartPLS.
